Code Highlighter

Syntax colours for the code in your cells.

Appearance


        

          

            
            
          

          

            
            
          

        

        
        
Dark themes use light text, which is hard to read without the fill.

        
        
        
Language applies to Highlight; Auto-detect picks one per cell. Changes apply the next time you highlight, so select cells and choose Highlight to restyle them.

Update Excel to use Code Highlighter

      
This add-in colours text inside cells, which needs a version of Excel that supports the Excel JavaScript API 1.18. Update Office, or use Excel on the web.
