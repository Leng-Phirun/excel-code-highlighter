Code Highlighter for Excel

Code Highlighter colours code inside worksheet cells, the way a code editor does.

Supported languages (31): Python, Bash and Linux shell commands, PowerShell, Windows Batch, SQL, JavaScript, TypeScript, Java, C#, VBA / Visual Basic, C, C++, Go, Rust, Kotlin, Swift, PHP, Ruby, R, Scala, Dart, Lua, HTML/XML, CSS, JSON, YAML, TOML/INI, Markdown, Dockerfile, Terraform/HCL and diffs.

Highlight code

  1. Type or paste code into a cell. Press Alt+Enter (Windows) or Option+Return (Mac) for a new line inside a cell.
  2. Select the cell, or a whole range of cells.
  3. On the Home tab, choose Highlight.

Only cells that hold text are changed. Numbers, dates and formulas are left alone.

Choosing the language

By default the language is detected separately for each cell, so a sheet can mix SQL, shell commands and Python. To force one language, pick it under Code Settings › Language; Highlight then uses it for every selected cell. Text with no sign of being code is set in a monospace font without colours.

Shell highlighting understands command lines copied from a terminal or documentation, including prompts such as $ and user@host:~$, flags, pipes, redirects, variables and here-documents.

Auto-highlight

Open Home › Code Settings and turn on Auto-highlight. From then on, any cell you type or paste code into is coloured in its detected language as soon as you finish editing it. Cells that don't look like code, such as notes and labels, are left alone. Auto-highlight works while Code Highlighter is running, which starts the first time you use it in a workbook. To have it running as soon as a workbook opens, tick Start Code Highlighter when this workbook opens in Code Settings and save the workbook.

Themes and fonts

Code Settings offers Dark+, Light+, GitHub Light, Monokai and One Dark themes, a choice of monospace fonts and sizes, and options to fill the cell with the theme's background, widen the column to fit the code and fit the row height. To restyle cells that are already highlighted, select them and choose Highlight again.

Remove highlighting

Select the cells and choose Home › Remove. The text becomes black and the cell fill is cleared; your code is not changed.

Requirements and limits

  • Excel for Windows or Mac (Microsoft 365) or Excel on the web, recent enough to support the Excel JavaScript API 1.18.
  • Excel shows at most 409 points of row height, so very long code in one cell is cut off on screen; the code itself is kept in full.
  • An Excel cell holds at most 32,767 characters.
