Privacy policy

Last updated: 18 October 2026

This policy covers Code Highlighter, an add-in for Microsoft Excel published by aries ("we").

What the add-in reads

Code Highlighter reads the text of the cells you select, of cells you edit while auto-highlight is on, and, when you choose Find code on this sheet, of the cells on the current sheet, so that it can colour them. All of this happens inside Excel on your device.

What leaves your device

Nothing that we receive. The add-in does not send your workbook contents, your code or any personal information to us or to anyone else. It has no accounts, no analytics, no cookies and no advertising.

What is stored

Your preferences (language, theme, font, auto-highlight and similar options) are kept in the add-in's local browser storage on your device; we never see them. If you choose to have Code Highlighter start when a particular workbook opens, Excel records that choice in that workbook, and the colours the add-in applies are saved in your workbook like any other formatting. You can clear the preferences by clearing the Office add-in cache.

Services the add-in relies on

When Excel loads the add-in, it downloads the add-in's files from our web host, GitHub Pages, and Microsoft's Office JavaScript library from Microsoft. Like any web server, these may record standard request details such as your IP address and browser type, as described in the GitHub General Privacy Statement and the Microsoft privacy statement. We do not use these records to identify you or track how you use the add-in. Excel itself is covered by Microsoft's privacy statement.

Changes

If this policy changes, we will update this page and the date above.
